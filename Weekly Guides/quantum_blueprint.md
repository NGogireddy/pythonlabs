## 📅 PHASE 1: THE 90-DAY PYTHON FLUENCY BOOTSTRAP
**Goal:** Build deep muscle memory in idiomatic Python and numerical mathematics to gain absolute confidence when interviewing.

### 🧱 The 20-Minute Daily Ritual
* **The Drill:** Complete 1 to 2 "Easy" problems on LeetCode or HackerRank every single day.
* **The Rule:** After solving a problem, rewrite it using an alternative approach (e.g., converting a standard loop into a list comprehension) to force syntax recall.

### 🗓️ Month 1: Python Core Fluency & Data Handling
*   **Week 1: Advanced Control Flow & Functional Python**
    * *Focus:* List, dictionary, and set comprehensions. Transitions from `for` loops to `lambda`, `map()`, `filter()`, and `zip()`. Unpacking sequences and using `enumerate()`.
    * *Action:* Complete **Week 1 Drill: The Quantum Data Preprocessor** (see end of document).
*   **Week 2: Robust Error Handling & File I/O**
    * *Focus:* `try-except-else-finally` blocks. Context managers (`with` statements). Designing custom exception classes for fragile environments.
*   **Week 3: Deep Dive into Built-in Modules**
    * *Focus:* `collections` module (`Counter`, `defaultdict`, `namedtuple`) and `itertools` module (`permutations`, `combinations`) to track system states.
*   **Week 4: Object-Oriented Python (OOP)**
    * *Focus:* Classes, `self`, dunder methods (`__init__`, `__str__`, `__repr__`, `__add__`), and inheritance.
    * *Milestone Project 1:* Build a command-line application simulating an enterprise banking ledger entirely from scratch using OOP, complete with type hinting and `pytest` unit tests.

### 🗓️ Month 2: Numeric Python & The Math of Quantum
*   **Week 5: Mastering NumPy Fundamentals**
    * *Focus:* Array creation (`np.zeros()`, `np.ones()`), indexing, slicing, and vectorised broadcasting operations (no manual loops).
*   **Week 6: Linear Algebra Execution via NumPy**
    * *Focus:* Matrix multiplication (`@` or `np.dot()`), determinants, transpositions, and calculating eigenvalues/eigenvectors using `np.linalg`.
*   **Week 7: Complex Numbers & Trigonometry**
    * *Focus:* Native complex number syntax (`z = 3 + 4j`), real/imaginary separation (`z.real`, `z.imag`), and absolute value/magnitude (`abs(z)`).
*   **Week 8: Data Visualization**
    * *Focus:* Rapidly plotting graphs, matrices, and state vectors using `matplotlib.pyplot`.
    * *Milestone Project 2:* Write a Python script that generates a random multi-dimensional matrix, calculates its eigenvectors, and plots the resulting vector transformations on a 2D grid.

### 🗓️ Month 3: Professional Engineering & The Quantum Bridge
*   **Week 9: Memory Management & Optimization**
    * *Focus:* Python garbage collection, mutable vs. immutable object management, and **Generators** (`yield`) for high-efficiency data handling.
*   **Week 10: Code Quality Tools & Documentation**
    * *Focus:* Integrating linters into your IDE. Ensuring 100% **PEP 8** style compliance using `black` or `flake8`. Writing clean docstrings.
*   **Week 11: Introduction to Qiskit Syntax**
    * *Focus:* Core Qiskit commands: initializing a circuit (`QuantumCircuit(qubits, bits)`), adding gates (`circuit.h(0)`, `circuit.cx(0,1)`), and measuring states.
*   **Week 12: Running Your First Simulation**
    * *Focus:* Calling a local classical simulator backend, executing the circuit, and extracting execution counts as a dictionary.
    * *Milestone Project 3:* Write a PEP-8 compliant, OOP-styled program that creates a Bell State (entangled qubits) in Qiskit, simulates it 1,024 times, and prints a formatted ASCII histogram of results.
